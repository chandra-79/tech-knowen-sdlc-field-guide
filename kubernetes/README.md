# TechKnowen Kubernetes & Cloud

A separate learning programme within the SDLC Field Guide. Original explanations, diagrams and practical tasks use a fictional Harbour Bank information service.

Read `index.html` directly or open the published `/kubernetes/` route. No runtime packages, remote fonts or mandatory network calls are needed for reading. Labs require the stated local, VM or cloud environment. No download controls are added.

`src/author.py` and the track modules contain reviewed original lesson material. `labs/` holds original fixtures; the build embeds them as readable code, not automatic execution. `content/course.json` is generated by `python3 build.py`. The same command builds the self-contained page. `--ckad-only` builds the initial foundation/CKAD checkpoint.

Current technical sources and execution boundaries are shown on the Sources page. Personal progress and evidence notes stay in browser local storage. They are not certifications or independently verified lab results.
